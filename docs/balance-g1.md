# 難易度の調整（G1）

2026-10-10。Claude がシミュレーターで数値を決めた。測り方は docs/sim/README.md の「G1」。

## 何が問題だったか
- 寄り道なしで進んだときのLvと推奨Lvが大きくずれていた（d3で−7、d8で−24）。推奨Lvは何周も稼ぐ前提になっていた
- 連鎖アシストと連鎖技で味方が強くなり、推奨Lvではどのダンジョンもクリア率100%・9〜15ターンで終わっていた
- d1〜d3のボスだけ古い決まり（HP半分で攻撃1.3倍、大技2.5倍）で、d3のボスが急に強く感じられた
- 3c00ed1（ボスHPだけを上げた調整）は取り消し済み

## 方針
- 寄り道なしで進められる。ボスで負けても、1〜2周すれば勝てる
- 強さは「一撃で倒しにくる」ではなく「長めの戦いで少しずつ削ってくる」。ボスの通常攻撃は推奨LvのチームHPの12〜30%、大技はその1.8倍
- 負ける場所はボスに集める（雑魚の攻撃はボスより控えめ）
- 連鎖技・能力アップ（docs/design-growth.md）の数値は変えていない。このままで目標に入った

## ボットについて
- 1ターン平均6〜7コンボ（落ちコン込み）、10コンボ以上は約17%のターン
- 連鎖技は1ターンあたり：強攻撃 約0.32回、必殺技 0.18〜0.37回、超必殺 0.11〜0.19回、奥義 約0.05回（Lv35以上）
- 人はボットより回復のタイミングがうまい一方、コンボはばらつく。実際に遊んだ感想で、ボスの攻撃（ボス攻撃の倍率）を見直す

- 追加ダンジョンのテストの推奨Lvを新しい値に
