# ダンジョン4〜8 仮データ（フェーズC中盤）

敵データの正本は index.html の DATA 内 DUNGEONS。以下はその一覧です。HPは6×5盤面の基準値で、7×6では1.5倍。攻撃値は通常攻撃の基準値です。

推奨Lvの能力倍率は 1 + 0.03 × (Lv − 1)。d4〜d8で1.69／1.87／2.05／2.23／2.41倍になることを基準に、HP・回復の伸びとフロア数を踏まえた目安を置きました。攻略バランスと目標ターン数は次回のシミュレーターで調整します。

技は通常攻撃に追加して発動。先制は登場演出のあと、各敵1技。every:N と turn:N はフロア内の確定ターン数。属性吸収とコンボ吸収は次の攻撃3回、暗闇は付与したルーンが残る場合に次の確定2回で解除。再生は最大HP5%。上限と根性は期間なし（根性は1回だけ）。

通常攻撃は基準値の0.9〜1.1倍。以下の新ボスは3回の通常攻撃ごとに1.8倍の大技を使う。d8最終形態のみ2回ごと。d1〜d3の既存の敵データ・行動は変更していません。
