# RUNE OVERDRIVE 演出の作り直し指示書（v2.1）

2026-10-07

## F0. この指示書の使い方

試遊の感想は「キャラビジュアルがダサい」「演出が単調すぎて飽きる」の2つでした。この指示書は後者を直すためのものです。キャラの絵は、Midjourneyの素材を入れる指示書5.1（フェーズB）で別に直します。ただし、この指示書の演出は、絵が入る前（今の紋章とコード描画の敵）でも動くように作ります。

依頼は「演出指示書のF2を実装して」のように、この節番号で来ます。

### 単調に見える原因（今のコード）

1ターンの流れが、毎回まったく同じ形をしています。

- **攻撃が全員同じ**：`fxAttack()` と `launch()` は、どの属性でも「光の玉が弧を描いて飛ぶ」だけ。違うのは色だけで、音も `Sound.sfx.hit()` の1種類。
- **コンボの盛り上がりが10で止まる**：段階は3・5・7・10で終わり。ポップ音も3オクターブで頭打ちになる。消え方はグループの形に関係なく同じ。
- **敵の攻撃が全種類同じ**：`fxEnemyAtk()` は、センチネル・ウィスプ・ゴーレム・ボスのどれも「少し大きくなって戻る＋揺れ」。予告もない。
- **倒し方が1種類**：`killEnemy()` は、最後の1体でもボスでも同じ砕け方。
- **キャラが画面にいない**：戦闘中にキャラが出るのは、スキルのカットインだけ。

### 直し方の原則

1. **同じものを2回続けて見せない**：同じ演出でも、角度・位置・本数を毎回少し変える（見た目だけなので `Math.random()` を使ってよい）。
2. **普段は速く、特別な瞬間だけ長く**：普通の攻撃は今より短くし、そのぶんフィニッシュ・トドメ・大技に時間を使う。1ターンの目標6秒（指示書3.1）は変えない。
3. **敵とキャラに個性を出す**：種類ごとに違う動き、キャラごとに違う言葉。
4. **盛り上がりに天井を作らない**：10コンボの先にも、まだ見たことのない段階を用意する。

### 守ること

- **計算は変えない**：F1〜F5はすべて演出だけの変更。`resolveTurn()` などのLOGICの中には触れない。新しい演出は、今ある出来事（`pop`・`attack`・`enemyAtk` など）から演出側で決める。テストの結果が変わってはいけない。
- **設定を効かせる**：「演出速度」「画面揺れ・振動」「フラッシュ軽減」と `prefers-reduced-motion` を、新しい演出すべてに効かせる。フラッシュ軽減では、画面全体の点滅を1秒に3回までにする。
- **重くしない**：新しい絵（斬撃・光の柱・葉・爪・レーザーなど）は、`buildSprites()` と同じく画面サイズが決まったときに作り置く。
- **時間の見積もり**：新しく足した待ち時間は、すべて `estimateDuration()` に足す。20コンボのターンが6秒以内、早送りで2.5秒以内のまま。
- **カメラは必ず戻す**：F2のズームは演出中だけにし、`startInput()` で必ず元に戻す。指の位置と盤面のマスがずれないこと。

## F1. 演出見本（デバッグ）

ほかの節の確認に使う画面を、最初に作ります。25ターン遊ばなくても、すべての演出をボタン1つで見られるようにするためです。

1. デバッグ画面（`openDebug()`）に「演出見本を開く」ボタンを足す。
2. 演出見本は、ダミーの戦闘画面を開く。敵はセンチネル・ウィスプ・ゴーレムの3体（属性ばらばら）と、切り替えでボス1体。敵は倒れず、攻撃もしてこない。セーブには何も書かない。
3. 盤面の上に、ボタンの帯（横スクロール可）を重ねる。押すと、作った出来事リストを `playEvents()` で再生する。
   - 攻撃：紅・蒼・翠・輝・冥（通常版と大技版）
   - フィニッシュ、最後の1体のトドメ、ボスのトドメ
   - 敵の攻撃：センチネル・ウィスプ・ゴーレム・ボスの通常・ボスの大技
   - コンボ：5・10・13・16・20コンボの連鎖
   - オーバードライブ
   - セリフ（ランダムな1人）
   - 「元に戻す」（敵と盤面をリセット）
4. 「演出見本を閉じる」でホームに戻る。

## F2. 属性ごとの攻撃とフィニッシュ

### 属性ごとの攻撃

光の玉を飛ばすのをやめ、属性ごとに違う「形」で攻撃します。

| 属性 | 攻撃の形 | 当たったとき | 変化のつけ方 |
|---|---|---|---|
| 紅（炎） | 敵の上に、三日月形の斬撃が2本、交差して走る | 火の粉が上へ舞い上がる | 斬撃の角度を毎回±20度変える |
| 蒼（水） | パーティ欄から敵へ、細い水の槍がまっすぐ速く伸びる | 水しぶきが横に広がり、波紋の輪が2重に出る | 出る位置を左右にずらす |
| 翠（風） | 葉の刃が3枚、らせんを描いて敵へ向かう | 葉が渦を巻いて散る | らせんの向き（右回り・左回り）を毎回変える |
| 輝（光） | 画面の上から敵へ、光の柱が一瞬で落ちる | 十字の光が広がる | 柱の本数を1〜2本で変える |
| 冥（闇） | 敵の足元から、黒紫の爪が3本突き上げる | 闇の粒が一度中心へ吸い込まれてから弾ける | 爪の位置と傾きを変える |

- **大技版**（共鳴・ライン消し）：大きさ1.6倍、本数を増やす（斬撃3本、柱3本、爪5本など）。
- **当たった音**：属性ごとに違う音にする（紅＝燃える音、蒼＝水しぶき、翠＝風切り、輝＝高い鈴、冥＝低くこもった音）。
- **弱点**：WEAK! の表示に加えて、当たった瞬間に属性色の短い光（0.08秒）を敵に重ねる。
- **かかる時間**：1人分の攻撃は今の `SHOT_TIME`（0.35秒）以下にする。5人の攻撃は、前の人の攻撃が当たる前に次が始まってよい（重ねて見せる）。

### フィニッシュ

そのターンの最後の攻撃を、特別に見せます。

1. **条件**：そのターンで最後の `attack` イベントで、かつ「コンボ数が `FINISH_COMBO`（7）以上」か「その攻撃で敵を倒す」とき。
2. **溜め**：攻撃の直前に、画面が少し暗くなり、`FINISH_WINDUP`（0.15秒）だけ時間がゆっくりになる。
3. **顔の帯**：担当キャラの顔（なければ紋章）を、画面の上3分の1を斜めに横切る細い帯で `CUTIN_MINI_TIME`（0.35秒）見せる（F5）。
4. **カメラ**：画面全体を、狙った敵を中心に `CAM_FINISH_ZOOM`（1.12倍）までズームする。
5. **攻撃**：その属性の大技版を出し、ヒットストップを入れる。
6. **戻す**：`CAM_TIME`（0.18秒）でカメラを戻す。

### 最後の1体のトドメ

フロアの最後の敵を倒した攻撃は、フィニッシュよりさらに大きく見せます。

- スローモーション0.6秒、カメラを `CAM_KILL_ZOOM`（1.25倍）までズーム、白い光（フラッシュ軽減を守る）。
- 敵の破片の一部を、画面の手前（大きく、速く）へ飛ばす。
- ボスのトドメはF4の専用演出を使う。

## F3. コンボの盛り上がり

1. **大きなコンボ数を常に出す**：連鎖中は、盤面の右上の外側に大きなコンボ数を出し、増えるたびに跳ねさせる。数字の色は段階ごとに変える。今の、消えた場所に出る「n COMBO」の文字は小さめにして残す。
2. **段階を足す**：今の3・5・7・10に、13・16・20を足す。表示は 13＝「RUNE STORM」、16＝「ARCANA BURST」、20＝「OVERLOAD」。それぞれ専用の色と、少しずつ大きくなる文字。
3. **音を天井まで伸ばす**：ポップ音は5コンボごとに上がり続けるようにする（今の3オクターブの上限を外し、聞こえる高さで止める）。10コンボ以上は和音を重ねる。
4. **背景が反応する**：コンボのたびに、背景の柱の縁が1本ずつ光る（左右交互）。10コンボで全部光り、ターンの終わりにゆっくり消える。
5. **盤面の枠が反応する**：コンボ数に応じて金の枠が明るくなる。13コンボ以上で、枠に沿って光が一周する。
6. **溜めを作る**：5コンボ目と10コンボ目の直前だけ、間隔を `COMBO_ANTICIPATION`（1.5倍）にする。
7. **消え方を形で変える**：

| 消えた形 | 消え方 |
|---|---|
| 3個 | 割れて、破片が散る（今に近い） |
| 4〜5個 | 中心から光ってから割れる |
| 6個以上、ライン | 横一閃に切れてから消える |
| クロス | 十字に光が走ってから消える |
| コア（3×3） | 中心へ吸い込まれてから爆発する |

## F4. 敵の個性

### 攻撃の予告

「あと1」になった敵は、次のターンに攻撃することを見た目で知らせます。

- センチネル：目が属性色に強く光り、細い光の線が目から少しはみ出す。
- ウィスプ：棘が逆立つように、ゆっくり大きくなる。
- ゴーレム：少し上に持ち上がり、後ろへ傾く（振りかぶる姿勢）。
- ボス：全身が脈打ち、足元の輪が速く回る。

### 種類ごとの攻撃

| 敵 | 攻撃の動き |
|---|---|
| センチネル | 目から細いレーザーがパーティ欄へ一直線に走り、当たった所に焦げ跡の光が残る |
| ウィスプ | 棘を3本、パーティ欄へ飛ばす |
| ゴーレム | 跳び上がって叩きつける。盤面全体が下に沈み、ルーンが一瞬跳ねる |
| ボス（通常） | ボスの属性で、F2の攻撃を逆向き（敵からパーティ欄へ）に使う |
| ボス（大技） | 画面が暗くなる → 技名 → 属性の大技版を画面いっぱいに → 強い揺れ |

### 被弾のリアクション

- 攻撃が来た方向と反対へ傾く（今は横にずれるだけ）。
- 大ダメージ（敵の最大HPの20%以上）では、縦につぶれてから戻る。

### ダメージのひび

- HPが75%・50%・25%を切るたびに、敵の絵の上にひびの線を足す（`CRACK_STEPS`）。ひびが入る瞬間に、小さな破片が落ちる。
- ボスは50%を切ったとき、結晶の一部が折れて落ちる（絵の上に重ねる表現でよい）。

### 倒し方

- 雑魚の倒し方を3種類にし、毎回ランダムに選ぶ：砕け散る（今）／光になって上へ昇る／縦に割れて崩れる。
- ボス：全身にひびが走る → 0.5秒止まる → 光の柱とともに砕ける → 破片が画面手前へ飛ぶ。

## F5. キャラの存在感

キャラが「その場にいる」と感じられるようにします。絵がなくても紋章で動き、フェーズBで顔の絵が入ったら自動で顔に変わるように作ります。

### セリフ

1. アイコンの上に吹き出しを `BARK_TIME`（1.2秒）出す。1ターンに出すセリフは1つまで（スキルとODは別枠）。
2. 出す場面と確率：

| 場面 | 誰が | 確率 |
|---|---|---|
| スキルを使った | 使った人 | 必ず |
| ODが始まった | リーダー | 必ず |
| フィニッシュ | 担当した人 | `BARK_FINISH_RATE`（30%） |
| 最後の1体のトドメ | 倒した人 | `BARK_KILL_RATE`（50%） |
| チームHPが25%を切った直後 | ランダムな1人 | 1フロアに1回まで |
| 勝利 | リーダー | 必ず（結果画面へ移る前） |

3. セリフは `DATA` の各キャラに `lines: { skill, finish: [2つ], pinch, od, win }` として持つ。中身は付録Aの表を使う。
4. 設定に「キャラのセリフ」（オン／オフ）を足す。セーブの `settings` に `barks: true` を足し、古いセーブではオンにする。

### 顔の帯とODの並び

- **顔の帯**：F2のフィニッシュで使う。今のスキルのカットイン（`cutIn()`）の短い版で、時間は止めない。
- **ODの並び**：ODの時間停止（`fxOD()`）の間に、5人の顔（なければ紋章）を左から順に0.08秒ずつ並べて光らせ、そのあと「OVERDRIVE」の文字を出す。時間停止の長さは今のまま。

### アイコンの動き

- 操作待ちの間、アイコンがゆっくり呼吸するように拡大縮小する（`ICON_BREATH`、1.5%）。
- 攻撃するキャラのアイコンは、今より大きく前へ跳ねる。
- チームHPが25%を切っている間は、アイコンが少し赤く脈打つ。

## F6. ターン数を短くする（数値の調整）

同じ演出を何度も見ると飽きるので、1ダンジョンのターン数を減らします。1ターンを「考える＋動かす＋演出」で12〜15秒とすると、今の平均25〜45ターンは5〜10分かかり、長すぎます。

- **目標の平均ターン数**：ダンジョン1は12〜18、2〜3は16〜24、4〜8は20〜30。
- **クリア率の目標**：指示書6.3の表のまま変えない。
- **変えてよいもの**：敵のHPと攻撃の数値だけ。計算の式は変えない。
- **測り方**：調整中は `node tools/sim.mjs --runs 50`、最後だけ200回。変更前後の表を `docs/worklog.md` に残す。

## F8. 連鎖アシスト（落ちコンを増やす）

試遊の感想「もっと連鎖を出して爽快感がほしい」への対応です。この節だけは見た目ではなく、ゲームのルール（LOGICの中の落下）を変えます。

### ルール

1. ルーンが消えて新しいルーンが降ってきたあと、確率 `CHAIN_ASSIST`（0.78）で、新しく降ってきたマスを1つ選び、まわりのルーンと3つそろう色に変える。そろう組み合わせがなければ何もしない。
2. 2回目以降の落下では、確率に `CHAIN_ASSIST_DECAY`（1.0＝下げない）を1回ずつ掛ける。1ターンに色を選ぶのは `CHAIN_ASSIST_MAX`（12）回まで。
3. OD中は少し強める：確率 `CHAIN_ASSIST_OD`（0.8）、`CHAIN_ASSIST_DECAY_OD`（1.0）、最大 `CHAIN_ASSIST_MAX_OD`（15）回。ODを「連鎖祭り」にする。
4. 数字の目安：10連鎖（奥義の候補）が、普通のターンで約25回に1回、OD中で約5回に1回出る。
5. 乱数は今までどおり `rng.board` を使う。同じ種なら同じ結果になる。毒の色は選ばない。
6. 落下の出来事（`fall`）に、色を選んだマスを `guided: [行, 列]` として足す。`fall()` は、引数 `assist` を渡さなければ今までと同じ動きをする。

### 見せ方

- **連鎖の数**：ぷよぷよと同じ数え方で、落ちてきたルーンで最初に消えたグループのときに「2連鎖」「3連鎖」…を盤面の上のほうに大きく出す。5連鎖からは虹色。連鎖のたびに専用の音（回数が増えるほど高く、和音が厚くなる）を鳴らし、4連鎖からは画面を揺らす。
- **予告のきらめき**：色を選んだマスは、着地した瞬間にきらっと光らせ、短い音を鳴らす。

### 測った結果（ランダムな道筋を100本試すボット、普通8,000ターン・OD中3,000ターン）

| 条件 | 平均コンボ | 3連鎖以上 | 5連鎖以上 | 7連鎖以上 | 10連鎖以上 |
|---|---|---|---|---|---|
| 今まで（普通のとき） | 3.4 | — | — | — | 0% |
| 連鎖アシスト入り（普通のとき） | 6.0 | 66% | 33% | 15% | 4.0%（約25回に1回） |
| 連鎖アシスト入り（OD中） | 9.4 | 83% | 60% | 40% | 21.5%（約5回に1回） |

将来、連鎖の段階で技を出す案（3連鎖で強攻撃、5連鎖で必殺技、7連鎖で超必殺技、10連鎖で奥義）を入れるときは、この割合を前提にする。

コンボが増えるぶん与ダメージが上がり、クリア率が上がって、ターン数は減る。`node tools/sim.mjs` を回し直し、クリア率が指示書6.3の目標に入るよう敵のHPを調整する。ターン数が減るのは、F6の目的に合っている。
