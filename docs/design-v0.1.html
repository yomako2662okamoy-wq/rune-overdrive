この設計書の使い方

AIに実装を頼むときは「設計書の3.3と8.5を実装して」のように章番号で指定し、1回に1フェーズずつ進める（第9章）。数値はすべて第10章に集めてあるので、遊んでみて調整するときはそこだけ触ればいい。

1ゲーム概要

1.1コンセプト

パズドラに代表される「ルーンを自由に動かしてそろえる」タイプのパズルRPG。操作の仕組みはこのジャンル共通のものを使い、世界観・キャラクター・名前・絵はすべてオリジナルで作る。

体験の核は二段構えにする。

  • 考える気持ちよさ：4秒の間に盤面を読み、どこまで連鎖をつなげるかを計画する。
  • 解き放つ気持ちよさ：指を離した瞬間から、つないだ連鎖が音と光で一つずつ炸裂していく。

この「溜めて、放つ」を1ターン5秒前後で何十回もくり返すのがゲームの骨格。

1.3このゲームならではの要素

  • オーバードライブ（OD）：1ターンに10コンボ以上つなぐと発動。時間が止まる演出のあと、次のターンは盤面が全部強化ルーンになり、攻撃1.5倍・操作時間＋2秒。「10コンボを狙う」というはっきりした目標が生まれる。
  • 共鳴とプリズム：同じ色を3グループ以上消すと「共鳴」、6種類すべてを消すと「プリズム」。消し方によって演出そのものが変わる。
  • 盛り上がるBGM：コンボ数に応じてBGMの楽器が一つずつ増える。音を聞くだけで「今いい感じ」が分かる。

3パズル仕様

3.1盤面とルーン

盤面は横6列×縦5行の30マス。ルーンは6種類。色だけでは見分けにくい人のために、すべてのルーンに形のマークをつける。

ルーン色マーク役割
紅フレア赤三角紅属性キャラの攻撃
蒼アクア青しずく蒼属性キャラの攻撃
翠リーフ緑ひし形翠属性キャラの攻撃
輝ルクス金星輝属性キャラの攻撃
冥ノクス紫三日月冥属性キャラの攻撃
命ライフ桃ハートチームHPの回復

3.2操作ルール

  • 盤面のルーンを1つ指でつかみ、そのまま盤面上を自由に動かせる。指が通ったマスのルーンと位置が入れ替わる。
  • 操作時間は4.0秒。指が触れた瞬間ではなく、最初に入れ替えが起きた瞬間から数え始める（つかんだまま考えるのはタダ）。
  • 指を離すか、時間切れで確定する。
  • 残り1秒で時間バーが赤くなり、時計の音が鳴る。バーは点滅させない。
  • つかんでいるルーンは1.2倍に大きくし、指で隠れないよう指の位置より40px上に表示する。
  • 斜め移動は最初のバージョンでは入れない（上下左右のみ）。v1.1で対応する。

3.3消去ルール

  • 同じルーンが縦か横に3つ以上まっすぐ並ぶと消える。
  • 消える並び同士が同じ色で上下左右につながっていれば、L字・T字・十字でもまとめて1コンボ。
  • 消えたあと、上のルーンが落ちてきて、空いたところに新しいルーンが降ってくる。そこで新しくそろえば「落ちコン」として続けて消える。
  • 1ターンのコンボ数は、消えたグループの数の合計（落ちコン込み）。
  • 初期盤面は、最初からそろっている所がないように作る。
  • 新しいルーンの色はランダム。ただし乱数は「シード付き」にして、同じシードなら同じ盤面を再現できるようにする（バグ調査用）。

3.4特別な消し方

名前条件効果
クロス5個を十字の形で消す命なら回復量2倍。それ以外はその攻撃が敵の防御を無視する
ライン横一列6個をまとめて消すその色のキャラの攻撃が敵全体への攻撃になる
コア3×3の正方形（9個）で消す消したあと、同じ色の強化ルーンが盤面に3個生まれる

3.5強化ルーンと妨害ルーン

  • 強化ルーン：縁が光っているルーン。1個消すごとにその色の攻撃が6%上がる。オーバードライブやスキル、コア消しで生まれる。
  • 妨害ルーン（v1.1以降）：ロック（動かせない。消すと解除）、毒（消すとHPが減る）、暗闇（2ターンの間、種類が見えない）。ボス戦のギミックに使う。

4バトル仕様

4.1パーティ

  • 5体編成（リーダー1体＋サブ4体）。
  • キャラは紅・蒼・翠・輝・冥の5属性のどれか。命はキャラの属性にはならない。
  • チームHPは5体のHPの合計。回復力は5体の回復値の合計。

4.2攻撃の流れ

消したルーンと同じ属性のキャラが攻撃する。命ルーンを消すとチームHPが回復する。攻撃は合計コンボ数の表示のあと、紅→蒼→翠→輝→冥の順に0.08秒ずつずらして飛ばす。

4.3ダメージ計算

キャラ1体の攻撃 ＝ 攻撃力 × 消去倍率 × コンボ倍率 × 属性相性 × リーダー倍率 × 強化倍率 × OD倍率
倍率決め方例
消去倍率その色の各グループについて「1 ＋（個数 − 3）× 0.25」を足し合わせる3個＝1.0、4個＝1.25
コンボ倍率1 ＋（コンボ数 − 1）× 0.258コンボ＝2.75
属性相性有利2.0、不利0.5、それ以外1.0（4.4）紅→翠＝2.0
リーダー倍率リーダースキルの効果紅属性2.5倍
強化倍率1 ＋ 強化ルーンの数 × 0.063個＝1.18
OD倍率オーバードライブ中は1.5、普段は1.01.5
共鳴・プリズム発動したらさらに×1.2／×1.5（4.8）1.2

最後に敵の防御を引く（最低1ダメージ）。回復量は「回復力 × 命の消去倍率 × コンボ倍率」。

計算例

攻撃力1,000の紅キャラ。紅を3個と4個の2グループ消し、全体で8コンボ。敵は翠属性（紅が有利）、リーダー倍率2.5、強化ルーンなし。

消去倍率＝1.0＋1.25＝2.25　コンボ倍率＝1＋7×0.25＝2.75

1,000 × 2.25 × 2.75 × 2.0 × 2.5 ＝ 30,937（小数点以下切り捨て）

4.5敵

  • 持っている値：HP、防御、攻撃力、属性、行動カウント。
  • 行動カウントは頭の上に数字で出す。毎ターン1減り、0になると攻撃して元の数に戻る。
  • ボスは行動パターンを持つ（例：3ターン目に大技、HPが50%を切ると怒り状態）。
  • 登場直後に先制攻撃してくるボスもいる。

4.6スキル

  • アクティブスキル：ターンが経つとたまる（例：8ターン）。たまるとアイコンが光り、タップで発動。発動時はカットイン演出（5.6）。例：盤面の命を紅に変える／盤面を作り直す／次のターンの操作時間＋3秒。
  • リーダースキル：リーダーにしたキャラだけ有効で、常に効いている。例：紅属性の攻撃2.5倍／6コンボ以上で全員の攻撃3倍。

4.7オーバードライブ（OD）

  • 発動条件：1ターンで10コンボ以上（落ちコン込み）。
  • 画面上部のODゲージが、そのターンのコンボ数に合わせて伸びていく（10で満タン）。ゲージはターンをまたいでは貯まらない。
  • OD中（次の1ターン）：盤面のルーンが全部強化ルーンになる／操作時間＋2秒／攻撃1.5倍／降ってくるルーンが同じ色になりやすい（落ちコンが起きやすい）。
  • OD中にもう一度10コンボを出すとODが続く。最大3ターン。

4.8共鳴とプリズム

  • 共鳴：同じ色を1ターンに3グループ以上消すと発動。その色のキャラの攻撃が1発にまとまり、大きな一撃として飛ぶ。攻撃×1.2。
  • プリズム：1ターンで6種類すべてのルーンを消すと発動。全員の攻撃×1.5。

5演出設計

このゲームの気持ちよさの半分以上は演出が作る。この章では「何を、いつ、どれくらい強く」見せるかを決める。

5.1演出の4原則

  • 溜めて、放って、余韻：大きな演出は「溜め（0.2〜0.5秒）→炸裂（一瞬）→余韻（0.5〜1秒）」で作る。炸裂だけだと、派手でも印象に残らない。
  • だんだん強く：同じ演出をくり返さず、コンボが増えるごとに一段ずつ強くする。音程が上がり、揺れが大きくなり、色と文字が増える。
  • 止めて、強く：大きな一撃の瞬間に画面を0.05〜0.15秒だけ止める（ヒットストップ）。止まった一瞬が「重さ」になる。
  • 音・画・振動は同じ瞬間に：3つがずれると気持ちよさが一気に落ちる。すべての演出を一つのタイムライン（8.2の演出ディレクター）から鳴らす。

5.4オーバードライブ発動の絵コンテ

  1. 時間停止（0.30秒）：10コンボ目が弾けた瞬間、すべての動きが止まり、画面が暗く、色が抜ける。BGMも一瞬無音に。
  2. 亀裂（0.30秒）：画面の中央から光の線が放射状に走る。
  3. 文字が飛び込む（0.35秒）：「OVERDRIVE」の文字が奥から手前に飛び込んできて止まる。同時に低音の「ドーン」と振動。
  4. 色が戻る：淡い虹色のフラッシュが1回だけ。真っ白な強い光にはしない。
  5. 強化の波（0.50秒）：盤面のルーンが下の行から順に強化ルーン（光る縁）へ変わっていく。
  6. 全開：BGMが全パート＋コーラスに。背景がオーロラのようにゆっくり色を変え、画面の縁がBGMのテンポに合わせて脈打つ。

2回目以降は、タップで1〜3を飛ばせる。

5.5ボス登場

暗転→敵の属性色の「WARNING」帯が上下から流れてくる→心臓の音が2回→ボスのシルエット→光が当たって姿が現れ、名前が出る。合計2.5秒。同じボスの2回目以降はタップで飛ばせる。

5.6スキルのカットイン

画面を斜めに横切る帯に、キャラの絵とスキル名を出す。0.8秒。その間は背景の時間を止める。帯の色はキャラの属性色。

5.7共鳴とプリズム

  • 共鳴：その色のキャラの攻撃弾が空中で1つに合体し、太い光線になって飛ぶ。効果音は消去音を3つ重ねた和音。
  • プリズム：6色の光の帯が画面を横切り、6つの音が順に鳴って和音になる。

5.8ダメージ数字

  • 属性の色で表示する。有利な属性のときは小さく「WEAK!」を添える。
  • 数字は0.3秒でカウントアップする（パラパラと増える）。
  • 桁が多いほど大きく出す。10万を超えたら、出る瞬間に小さなヒットストップを入れる。

5.10振動

Androidのブラウザは振動（navigator.vibrate）が使えるが、iPhoneのブラウザは使えない。振動は「あるとうれしいおまけ」とし、振動なしでも成立する演出にする。

5.11遊ぶ人への配慮（設定画面）

  • 演出速度：標準／高速（1.5倍）／最速（2倍・カットイン省略）。
  • 画面揺れ：オン／オフ。
  • フラッシュ軽減：全画面の光を半分以下の明るさにし、点滅をなくす。端末の「視差効果を減らす」がオンなら、最初からオンにする。
  • 点滅の上限：どの演出でも、光の点滅は1秒に3回まで（光に敏感な人への配慮）。
  • 色の区別：全ルーンに形のマークをつける（3.1）。

6ビジュアルと画面

6.1アートの方向性

テーマは「夜の祭壇に浮かぶ宝石」。背景は暗く色を抑え、ルーンとエフェクトだけが鮮やかに光る。背景が地味なほど演出が映える。光は加算合成（重なるほど明るくなる描き方）で表現する。キャラと敵の絵はMidjourneyで描き、背景を切り抜いて使う。

  • iPhoneの切り欠きやホームバーにかからないよう、上下はセーフエリアを空ける。
  • ブラウザでは画面の向きを固定できないので、横向きにされたら「縦にしてね」の表示を出す。

6.3高解像度でくっきり見せる

  • Canvasは画面の実際のピクセル数（devicePixelRatio、上限3）で描く。これをしないとスマホでは全体がぼやける。
  • ルーンは画像ファイルではなく、コードで描く図形にする。どんな画面でもくっきりで、ファイルも軽い。
  • 毎フレーム図形を描き直すと重いので、起動時に6種のルーンを一度だけ高解像度で描いて保存しておき（キャッシュ）、あとはそれを貼るだけにする。冒頭のデモもこの方法で描いている。
  • キャラ・敵の絵は表示サイズの2倍くらいで用意し、WebP形式で1枚200KB以下を目安にする。
  • 目標は秒間60フレーム。動きは「経過時間」で計算し、120Hzの端末でも速くならないようにする。

8.2一番大事なルール：計算と演出を分ける

指を離した瞬間に、そのターンの結果（どこが消えて、何コンボで、何ダメージか）を一気に全部計算してしまう。結果は「出来事リスト」にまとめ、演出係（演出ディレクター）がそれを上から順に、時間をかけて再生する。

  • 計算だけを確かめられるので、バグが見つけやすい。
  • 演出速度の変更やスキップが簡単（再生のスピードを変えるだけ）。
  • 演出をどれだけ派手にしても、計算が狂わない。

async function playEvents(events) {
  for (const ev of events) {
    if (ev.type === "match")      await fx.burst(ev);   // 光る→弾ける→音
    if (ev.type === "fall")       await fx.fall(ev);
    if (ev.type === "comboTotal") await fx.stamp(ev);
    if (ev.type === "attack")     await fx.attack(ev);
    if (ev.type === "defeat")     await fx.defeat(ev);
  }
}

8.5消去判定のしくみ

  1. 横に見て、同じ色が3つ以上続いている所に「消す印」をつける。
  2. 縦も同じように印をつける。
  3. 印がついたマスのうち、上下左右でつながっている同じ色をひとまとめにする（＝1コンボ）。この方法を「塗りつぶし（フラッドフィル）」と呼ぶ。
  4. まとまりの数をコンボとして数え、消えたマスを空にする。
// 手順1：横方向に、同じ色が3つ並んでいるマスに印をつける
function markHorizontal(board, marks) {
  for (let row = 0; row < 5; row++) {
    for (let col = 0; col < 4; col++) {   // 右に2つ先まで見るので col は 0〜3
      const c = board[row][col].color;
      if (c === board[row][col + 1].color && c === board[row][col + 2].color) {
        marks[row][col] = true;
        marks[row][col + 1] = true;
        marks[row][col + 2] = true;
      }
    }
  }
}

col < 4 がポイント。col + 2 まで見るので、列5をはみ出さないように0〜3で止めている。4つ以上並んでいる場合も、ずらしながら何度も印をつけるので全部に印がつく。

8.6動作を軽く保つ

  • 粒子は使い回す：最初に500個作っておき、消えたものを再利用する。毎回作って捨てると、ブラウザのメモリ掃除が走ってカクつく。
  • 同時に出す粒子は400個まで。
  • 光のぼかし（shadowBlur）は重いので粒子には使わない。かわりに、あらかじめ描いておいた「光の玉」を加算合成で重ねる。
  • 1秒間の平均が45フレームを下回ったら、自動で軽量モード（粒子半分・背景のオーロラなし）に切り替える。
  • アプリが裏に回ったら（visibilitychange）、描画と音を止める。

8.7指の操作

  • Pointer Events（pointerdown／pointermove／pointerup）を使う。タッチもマウスも同じコードで動く。
  • 盤面の上でスクロールや拡大が起きないよう、CSSで touch-action: none を指定する。
  • 指が盤面の外に出ても操作が途切れないよう、setPointerCapture を使う。

8.8PWA化（仕上げのとき）

manifest.json とアイコンを足すと、ホーム画面から全画面で起動できる。オフラインでも動かしたいときは service worker も足す。この3つだけは別ファイルになるが、ゲーム本体は単一HTMLのままでいい。
